# samsamhub

RIVALS hub for Roblox executors. Material Design 3 UI.

## Run

Paste [`samsamhub.lua`](./samsamhub.lua) into your executor and execute.

- **RightShift** — hide / show the window
- **Unload** — restores everything the script changed

## Auto execute

```
https://raw.githubusercontent.com/sammmmmm6767/samsamhub/main/samsamhub.lua
```

## Notes

- Configs are saved to the `samsamhub/` workspace folder (`samsamhub/configs`, `samsamhub/sounds`, `samsamhub/recordings`).
- UI library: [Material Design 3 for Roblox](https://github.com/engnyg/Material-Design-3-Roblox-lua-ui), patched in memory (gradient color pickers, mouse-button keybinds).
